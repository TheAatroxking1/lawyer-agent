# 零宽空格条头前缀

新增5份条号缺口的实际DocxExportReader调查确认福建省促进中小企业发展条例（source `7d32faca…`）第40段为两个U+200B紧接“第二十二条　正文”，前后21/23条闭合。U+200B及末尾零宽字符属于来源原文，不删除。

在已批准v4前缀恢复中增加独立前缀形态：段首1至8个连续U+200B，随后可有水平空白，再由现有ARTICLE_HEADING识别条头；超过8、混入其它控制字符/私用前缀、跨行均不匹配。保留现有U+E004/空括号加水平空白语义，沿用左右普通条号闭合、引号括号及章节/补充屏障、条后分隔和非空正文。仅精确v4，不改共享条号规则。上限只约束新格式候选的识别，不改变源文本。

本增量与数字内部空白独立，拟只改prefixed_article.py和其测试，避免同时修改Parser。真实验收用实际CLI来源/派生hash、连续1..51条、全部原字符/父子覆盖和replay；不得用前缀去除后文本代替原文。不得改GPU冻结文件或写业务库。
