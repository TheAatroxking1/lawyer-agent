# S1 分块保守回退对齐

依据已批准集合发布/层级分块方案，本切片修复引擎与“仅超长条拆分、无法确认结构则保留整条”的差异；不改变法规内容，不读写外部语料。

- [x] 更新测试：短条只产生完整父块、两短条不合并；长条按已保留的段落边界分类；缺失/空段落或段落拼接与权威全文不一致时只保留完整父块（即使全文超长）。先观察预期失败。
- [x] 引擎仅在全文长度超过 max_leaf_chars 且段落覆盖全文可核对时派生子块；首段条号不作为子块正文。只在可信长叶内滑窗，保留现有参数校验。
- [x] 验证窗口覆盖每个字符且不跨单位；测试阈值边界、未知/错误段落数据回退，父块哈希/原文不变。
- [x] 聚焦 pytest、Ruff、mypy，独立规格和质量审查；记录短条/歧义回退已完成，但直接挂条文的子块不等同完整款项嵌套树，CLI/S4 接线另验收。
