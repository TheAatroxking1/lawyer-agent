# 身份与授权上线前待复核项

这些待办不削弱当前安全默认值，也不表示任何生产外部依赖已经可用。负责人与完成日期由正式上线计划确定，复核证据必须归档并经安全负责人签署。

| 真实身份 Provider | 短信、邮件与微信 Provider 分别完成供应商安全评估、错误脱敏、限流、账号枚举防护、回调验签和故障演练；开发 Adapter 不作为生产验证证据。 |

所有项目完成前，生产发布状态必须保持为“未批准”。
