# 记住登录与真实会话历史

用户明确要求本机长期保持登录、登录后看到以前的会话并能继续测试。本增量按该需求直接修复，保留短期访问令牌、轮换刷新凭据、CSRF、账号/租户隔离和退出撤销。

## 登录

浏览器使用 HttpOnly 持久刷新 Cookie，访问令牌仍为10分钟。前端启动、过期和休眠恢复时自动续期；同页合并并发刷新，跨标签通过 Web Locks 串行轮换。网络故障不清空登录；明确撤销或凭据无效才提示登录。刷新令牌不进入 localStorage，账号密码不保存。

账号会话持续承担设备登录。选择租户改为为同一有效账号会话签发独立 tenant audience 访问令牌，不撤销账号会话；每次租户请求仍重新核对权威账号、有效成员、授权版本及资源范围。退出使两种令牌都失效。浏览器记住选择的租户并在账号续期后重新取得租户令牌。设备刷新有效期按长期记住设备策略滚动延续；主动退出、改密码、禁用或管理员撤销优先。

## 历史

新普通对话和消息保存在 MySQL，私有范围为租户和创建用户。服务端从已保存的完整消息组成模型上下文；用户消息先存，回答完成或中断时保存实际结果及明确状态。刷新页面、重新登录后能列出并打开。客户端不把整段会话作为权威历史上传，不允许伪造模型角色。

已有合同运行记录继续使用现有表及原件存储；增加按租户和创建用户分页列出运行记录的入口，统一在侧栏展示。打开记录通过已授权读取接口恢复结果及 PDF，不再次调用模型。新对话只切换当前工作区，不删除历史。普通聊天和合同记录各自拥有稳定 URL。

## 验收

访问令牌过期可自动恢复、浏览器重启可恢复、并发请求不重复轮换、切租户后账号功能仍可用、退出后不可恢复；其它账号及其它租户的历史不可见。普通聊天刷新后仍在，切换历史不会将延迟返回写入另一个对话，未完成回答不能显示完成。已有23页合同可从侧栏读取原件、批注及依据，不重新推理。
