# 显式无条号正文入库

关联 [真实全集发布](2026-09-06-full-real-corpus-release.md)。用户要求全部真实候选入库，包括无条号批复。

1. TDD 增加显式 `non_article_document` 模式；默认 `articles` 不变。正常 Parser 返回零条且正文非空才允许新模式；有条文、解析歧义及空正文拒绝。
2. 独立正文映射产生一个 `PARAGRAPH/正文` 权威单元，保留全部正文段落，辅助页脚不进入正文。Proof flag 和结构摘要绑定模式；普通条文摘要保持不变。
3. 正文长段按原段落内部有界分块，保留全文父块。报告区分 article_count=0 与 provision_count=1，读取器兼容旧报告。
4. 质量门禁核对 selection、Proof flag、单元层级和标记；仅匹配新模式时免条号序列检查，其余内容、覆盖、身份、来源和元数据门禁不变。
5. 聚焦单测 RED→GREEN、静态检查、第二份真实批复只读预检、隔离 MySQL 集成；禁止业务库清理及来源改写。
